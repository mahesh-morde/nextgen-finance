## 📖 Overview

**NexusAI Finance** bridges the gap between financial access and financial understanding. With the rapid growth of retail investing, many investors have access to markets but lack the deep financial knowledge required to navigate them safely.

Our platform transforms complex raw market data and diverse portfolios into **conversational, actionable intelligence** using advanced Generative AI and Retrieval-Augmented Generation (RAG).

## ✨ Key Features (Delivering on the Challenge)

| Hackathon Requirement | NexusAI Solution |
| :--- | :--- |
| **Explain Financial Products** | 🤖 **AI Co-Pilot:** Natural language explanations of complex instruments. |
| **Portfolio Risk Simulation** | 📈 **Risk Engine:** Simulates market shocks and calculates drawdowns. |
| **Detect Suspicious Patterns** | 🛡️ **Anomaly Detection:** Proactive flagging of unusual portfolio activity. |
| **Investment Summary** | 📄 **AI Summaries:** Plain-English, concise overviews of your holdings. |
| **RAG Architecture** | 🧠 **Knowledge Layer:** Deep integration with regulatory and financial contexts. |
| **Explainable AI** | 💡 **Transparent Recommendations:** Clear, justifiable AI advice. |

## 🛠 Technology Stack

This project is built on a modern, highly scalable, enterprise-grade foundation.

**Frontend Core:**
* Angular 18 (Standalone Components)
* NgRx Signals (State Management)
* Bootstrap 5 & Angular Material
* ApexCharts (Data Visualization)

**AI & Backend Layer (Architecture):**
* Retrieval-Augmented Generation (RAG)
* Financial LLM Integration
* Python / FastAPI
* Docker & Nginx Deployment
* Progressive Web App (PWA) Ready

## 🚀 Getting Started

To run the frontend platform locally:

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) and [Angular CLI](https://angular.io/cli) installed.

### 2. Installation
Clone the repository and install the dependencies:
```bash
git clone https://github.com/mahesh-morde/nextgen-finance.git
cd nextgen-finance
npm install
```

### 3. Development Server
Run the Angular development server:
```bash
ng serve
```
Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.
